ESP32 Wireless Sensor Network

A small wireless sensor network that collects readings from an ultrasonic sensor, a vibration sensor and an IR obstacle sensor, then sends the data to the cloud through an ESP32 gateway.

About the project

This project demonstrates sensor data collection, wireless device-to-device communication using ESP-NOW, and cloud monitoring over Wi-Fi. The sensor node reads the connected modules and sends the readings to a gateway ESP32. The gateway publishes the latest values to ThingSpeak, allowing the data to be viewed remotely.
